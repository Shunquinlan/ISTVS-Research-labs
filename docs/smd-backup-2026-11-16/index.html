Soil–machine interaction research

Testing how tires, tracks and tools work the ground

The Soil Machine Dynamics Laboratory (SMDL) runs controlled, year-round tests of how off-road machines interact with soil and granular materials, and uses the data to build and validate physics-based models.

For agriculture, construction, mining and extraterrestrial machines.
